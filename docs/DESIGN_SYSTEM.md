# Movbot Design System

## Visual direction
Premium fleet management: dark navy foundation, orange operational accent, restrained green/amber/red status semantics, high information density without visual clutter.

## Components
- 44–52px touch targets minimum.
- Rounded cards 18–22px.
- Bottom navigation is persistent for primary modules.
- Top bars are reserved for screen title, search, filter, or context actions.
- Status chips are semantic and compact.
- Sheets are preferred for contextual actions on mobile.
- Skeletons and explicit empty/error states are required for data-driven screens.

## Typography
Use a clear Arabic-capable font in the final brand build (Noto Sans Arabic or an approved licensed equivalent). Arabic is the default locale; English mirrors layout to LTR.

## Reference interpretation
The supplied reference images informed the information hierarchy, dark fleet-tracking mood, card density, map prominence, and vehicle visualization concept. They are not copied as screens or brand assets.
