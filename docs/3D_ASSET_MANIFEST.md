# 3D Asset Manifest

Production release requires actual GLB assets, validated and licensed.

## Candidate public-domain base
The Poly Pizza “Truck” by Quaternius is listed as FBX/GLTF and Public Domain (CC0). It can be used as a legally permissive base asset, subject to the current asset page/license terms. The product still needs a professional asset pass to create the four trailer variants and state-specific cargo visualization.

Reference: https://poly.pizza/m/cXw6oiFtZ8

## Required production assets
- tractor + curtain trailer
- tractor + flatbed
- tractor + sidewall
- tractor + refrigerated trailer

Each asset should have:
- consistent camera scale
- consistent wheel placement
- optimized GLB geometry
- compressed textures
- named nodes/materials
- cargo visibility groups
- loading/unloading state hooks
- validated bounds/origin

Do not ship an unrelated truck photo or a broken/missing model as a substitute.
